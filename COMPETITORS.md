# Конкуренты и аналоги

## Трекеры бэклога (Goodreads для игр)

- **[Backloggd](https://backloggd.com/)** — статусы, рейтинги, одиночные отзывы, популярный среди инди-аудитории
- **[PlayTracker](https://playtracker.net/)** — агрегация playtime из разных платформ, статистика
- **[Gamery](https://apps.apple.com/us/app/gamery-track-your-games/id1607763458)** — iOS, красивые 3D обложки, базовый трекинг
- **[GameTrack](https://apps.apple.com/us/app/gametrack/id1136800740)** — iOS, таймер сессий, Live Activity на Lock Screen

## Дневники / журналы

- **[GameJournal](https://apps.apple.com/in/app/gamejournal/id6737562465)** — ближайший аналог: заметки к сессиям с таймером. Но это лог сессий, не эволюция впечатлений
- **[Game Diary (Steam)](https://store.steampowered.com/app/3810140/Game_Diary/)** — скриншоты + заметки, без структуры отзыва
- **Notion/Bullet Journal шаблоны** — ручной трекинг, никакой автоматизации

## Наша ниша (чего нет ни у кого)

- Многослойный отзыв как единый нарратив (первое впечатление → дополнения → вердикт)
- Автоматические отметки playtime из Steam на каждой части
- Видимая эволюция мнения — как менялся вердикт и рейтинг по мере прохождения
- Живой отзыв, который растёт вместе с прохождением

У всех конкурентов либо один снэпшот-отзыв, либо разрозненные заметки к сессиям.
